# デザインシステム

テーマは「古き良き手書き」。方眼ノートに万年筆で書いたポートフォリオを、そのまま Web に置いたような佇まいを目指す。

## 原則

1. **紙とインク**だけで構成する。背景は紙、文字と線はインク。
2. **装飾は線で行う**。塗りつぶし、影、ぼかし、グラデーションは使わない。
3. **角は落とさない**。`border-radius` は 0。丸くしたいものは円（アバターなど）だけ。
4. **動きは控えめに**。ホバーで下線が引かれる、程度。スクロール連動やパララックスはしない。
5. **余白と罫線で階層を作る**。フォントサイズの段階は 4 つまで。

## カラー

Tottenham Hotspur の公式カラーを使う。

| トークン | ライト | ダーク | 用途 |
| --- | --- | --- | --- |
| `--paper` | `#FFFFFF` | `#132257` | 背景 |
| `--ink` | `#132257` | `#FFFFFF` | 文字、罫線、枠 |
| `--ink-soft` | `#132257` を 60% | `#FFFFFF` を 70% | 補足テキスト、日付 |
| `--rule` | `#132257` を 25% | `#FFFFFF` を 30% | 方眼、区切り線 |
| `--mark` | `#132257` | `#FFFFFF` | 選択中タグ、ボタンの塗り |

- 色は上記 2 色と、その透明度違いだけで組む。第 3 の色相は使わない。
- `globals.css` の `@theme` で Tailwind の既定パレット・角丸・影・ぼかしを `initial` にしているため、`text-gray-400` や `rounded-lg` は**クラスとして存在しない**。書いても何も起きないので、`bun run check:design` で機械的に検出する。
- 実装上のトークンは `bg-paper` `text-ink` `text-ink-soft` `border-rule` `bg-mark` の 5 つ。
- 「危険」や「エラー」も赤にしない。太い下線や `!` マークで示す。
- ダークモードは紙とインクを反転させるだけ。

## タイポグラフィ

| 役割 | フォント | 備考 |
| --- | --- | --- |
| 本文（日本語） | Zen Kurenaido | Google Fonts。手書きペン風、可読性が高い |
| 見出し（欧文） | Caveat | Google Fonts。サインのような筆致 |
| コード | JetBrains Mono | 等幅は手書きにしない。読めることを優先 |

- `next/font/google` で読み込み、`display: swap`、サブセットは `latin` と `japanese`。
- 見出しは 4 段階のみ: `h1` 2.5rem / `h2` 1.75rem / `h3` 1.25rem / 本文 1rem。
- 行間は本文 1.9、見出し 1.3。
- 強調は太字ではなく **波線の下線**（`text-decoration: underline wavy`）。

## 罫線と枠

- 罫線: `1px solid var(--rule)`。
- 枠: `2px solid var(--ink)`。カードは枠線だけで表現する。
- 背景の方眼: `background-image` の `linear-gradient` 2 本で 24px グリッドを描く。これは「色のグラデーション」ではなく罫線描画なので許可する。
- 手書き感はカードを 0.3〜0.4 度だけ傾ける（`hover:-rotate-[0.3deg]`）程度に留める。ライブラリ（rough.js など）は導入しない。
- シンタックスハイライトも 2 色で行う。キーワードは太字、文字列は斜体、コメントは薄いインク、関数名は点線の下線（`globals.css` の `.highlight`）。

## コンポーネント指針

| 部品 | 方針 |
| --- | --- |
| ボタン | 枠 2px、角 0、ホバーで `--mark` 塗り + 紙色文字。押下時は 1px 下にずらす |
| リンク | 常に下線。ホバーで波線に変える |
| タグ | 枠 1px の小さな箱。選択中は塗り |
| カード | 枠 2px。画像はモノクロ寄り（`filter: grayscale(0.2)`）で紙に馴染ませる |
| 入力欄 | 下線のみ（`border-bottom: 2px`）。フォーカスで太くする |
| ヘッダー | 罫線 1 本で区切る。ロゴはタイプライタ風ではなく手書きサイン |
| フッター | 罫線 1 本、著作権と SNS リンクのみ |
| 空状態 | 「まだ何もありません」を手書きで。ダミーで埋めない |

## 廃止したもの

旧実装から次を撤去した。

- ローディング画面（4.5 秒の固定遅延）
- Three.js の 3D シーン、バイナリレイン、パララックス
- Magnetic ボタン、スクロールプログレスバー
- グラデーション背景、`blur-[100px]` の装飾、ネオン風の影
- 7 セグメント表示とターミナル風 404（手書きの「ページが見つかりません」に置き換えた）
- Marquee のスキル表示（● と ○ の表に置き換えた）
- framer-motion、Three.js、Radix、react-icons、lucide などの UI ライブラリ（アイコンは `components/ui/Icon.tsx` の線画 SVG 12 個）

## アクセシビリティ

- コントラスト比は navy / white で 13:1 を確保しているため、透明度を落とす場合も 4.5:1 を下回らない（`--ink-soft` の 60% は 5.6:1）。
- `prefers-reduced-motion: reduce` で全アニメーションを停止する。
- フォーカスリングは `outline: 2px solid var(--ink); outline-offset: 2px`。消さない。
- スキップリンクを `<main>` の先頭に置く。
- 画像には必ず意味のある `alt`。装飾画像は `alt=""`。
